# tl_st25dv

Dynamic NFC/RFID tag IC with 4-, 16-, or 64-Kbit EEPROM, fast transfer mode capability Zephyr OS driver.
Supported: ICs ST25DV04KC, ST25DV16KC, ST25DV64KC.
